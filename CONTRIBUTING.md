# Contributing to Chrono Modern Clock

Thank you for your interest in contributing to Chrono Modern Clock!

We welcome developers who want to improve the functionality, design, accessibility, performance, and documentation of this project.

## 1. Getting Started

Before contributing, make sure you have:

- Git installed.
- A GitHub account.
- A modern web browser.
- A code editor such as Visual Studio Code.

No Node.js installation or build tools are required.

## 2. Clone the Repository

```bash
git clone https://github.com/ENG-JUMA-O/chrono-clock.git
cd chrono-clock
```

Open `index.html` in your browser or use the VS Code Live Server extension.

## 3. Create a Feature Branch

Create a separate branch for your contribution.

```bash
git checkout -b feature/your-feature-name
```

Use descriptive branch names, such as:

- `feature/improve-accessibility`
- `fix/clock-display`
- `docs/update-readme`

## 4. Development Guidelines

When contributing:

- Write clean, readable JavaScript.
- Maintain responsive layouts.
- Follow the existing HTML and CSS structure.
- Avoid unnecessary external dependencies.
- Test changes in different browsers and screen sizes.
- Preserve existing clock functionality.
- Consider accessibility and keyboard navigation.

## 5. Commit Your Changes

Use clear and descriptive commit messages.

```bash
git add .
git commit -m "Describe your contribution"
```

## 6. Submit a Pull Request

1. Push your feature branch to GitHub.
2. Open the Chrono Modern Clock repository.
3. Select Pull Requests.
4. Create a new pull request against `main`.
5. Describe your changes and why they are useful.
6. Submit your pull request for review.

## 7. Reporting Issues

When reporting a bug, include:

- A clear description of the problem.
- Steps to reproduce it.
- Expected behaviour.
- Actual behaviour.
- Browser and device information where relevant.

## 8. Code of Conduct

All contributors are expected to:

- Communicate respectfully.
- Provide constructive feedback.
- Respect other contributors.
- Submit original and properly credited work.
- Keep discussions professional and welcoming.

## 9. Recognition

We appreciate every developer who contributes to Chrono Modern Clock.

Contributors who make meaningful improvements help the project grow and become better for everyone.

Thank you for contributing!

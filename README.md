# Chrono Modern Clock

A responsive HTML/CSS/JavaScript clock dashboard.

## Run locally
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. No build step or npm dependencies are required.

## Features
- Live analog and digital clock
- 12-hour / 24-hour display
- Toggle seconds hand/readout
- Local timezone label and date
- Day-of-year, ISO week number, day progress
- Nairobi, London, and New York world clocks
- Stopwatch with start/pause/resume/reset
- Countdown timer with pause/resume/reset and completion toast
- Dark/light theme toggle with saved preference when browser storage is available
- Responsive layout and keyboard focus states
